# Security policy

Please report vulnerabilities privately rather than opening a public issue with exploit details. Include the affected version, reproduction steps, and whether the issue can expose audio, transcripts, provider keys, or encrypted artifacts.

Clarity treats transcript content as untrusted data, stores provider keys in macOS Keychain, sandboxes both renderers, keeps cloud optional, and redacts provider errors. Content protection is best effort and is not a guarantee of invisibility.
